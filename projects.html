FleetDash

Real-Time Fleet Tracking Dashboard

A full-stack fleet management dashboard for monitoring vehicles, visualizing live locations, managing fleet data, handling alerts, and generating operational reports through an interactive web interface.

Real-time vehicle location updates using Socket.io and Redis Pub/Sub.
Vehicle CRUD operations with MongoDB and Mongoose.
Interactive fleet map using React and Leaflet.
Overspeed and low-fuel monitoring with real-time alerts.
JWT-based authentication and protected routes.
PDF and Excel report export functionality.
Technologies
React.js TypeScript Node.js Express.js MongoDB Socket.io Redis Leaflet Recharts JWT

PROJECT 02

SyncDoc

Real-Time Collaborative Document Editor

A full-stack collaborative document editor designed for real-time multi-user editing. SyncDoc uses Yjs, CRDT-based synchronization, and WebSockets to keep shared document state synchronized across connected clients.

Real-time multi-user editing using Yjs and WebSockets.
CRDT-based synchronization for concurrent document changes.
Block-based document structure for headings, paragraphs, lists, and code.
MongoDB persistence using Mongoose models.
Server-side HTML sanitization using DOMPurify.
PDF document export using PDFKit.
Technologies
React.js TypeScript Node.js Express.js Yjs CRDT WebSocket MongoDB Mongoose DOMPurify PDFKit
